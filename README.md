# Smart Emergency Road Management System

## About the Project
The Smart Emergency Road Management System is a web-based project designed to demonstrate how emergency vehicles can receive traffic priority to help reduce delays during emergencies.

## Objectives
- To provide a simple interface for emergency vehicle selection.
- To demonstrate traffic signal changes for emergency vehicles.
- To display emergency route status and related information.
- To improve awareness of smart traffic management concepts.

## Features
- Emergency vehicle selection: Ambulance, Police, and Fire Engine.
- Traffic light status display.
- Emergency route visualization.
- Reset option to return to the initial state.
- Simple and user-friendly interface.

## Technologies Used
- HTML
- CSS
- JavaScript

## How to Run
1. Open the project website using the GitHub Pages link.
2. Select an emergency vehicle.
3. Observe the traffic light and route status changes.
4. Use the Reset button to return to the initial state.
